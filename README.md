# Portfolio CMS

A full-stack developer portfolio with a custom CMS.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- React / Next.js
- Tailwind CSS

## Features

- Admin login
- Manage projects
- Manage skills
- Manage blogs
- Manage experience
- Manage services
- Manage testimonials
- Contact messages
- Image upload
- REST API

## Run the Project

### Backend

```bash
cd backend
mvn spring-boot:run

Backend runs on:

http://localhost:8080

### Frontend

cd frontend
npm install
npm run dev

Frontend runs on:

http://localhost:3000

Admin

http://localhost:3000/admin
